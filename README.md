# Combo Rush

Каждые 10 минут: 5 мин подготовки + 5 мин событие. Очки = фишки × множитель → монеты → усилители → сброс на 50-м событии.

## Команды
Для всех:
- `/shop` — магазин (только вне события) · `/species` — выбор существа (пока 0 событий в забеге) · `/cosmetics` — косметика за эссенцию
- `/cr stats` · `/cr <игрок> stats` — статистика (игрок должен быть онлайн)
- `/cr reset` → `/cr reset confirm` — сброс прогресса (после 50 событий, не во время события)
- `/cr promo` — список акций · `/cr event` — текущее событие Режиссёра
- `/top` или `/cr top [рекорд|очки|ранги|убийства|события]` — таблица лидеров в чате (видны и офлайн-игроки), вкладки кликабельные

Для операторов: `/cr start`, `/cr end`, `/cr coins <n>`, `/cr essence <n>`, `/cr addscore <n>`, `/cr setevents <n>`,
`/cr promo start|stop|auto <id>` (auto — вернуть включение по датам), `/cr event list`, `/cr event next <id>` (принудительно задать следующее событие). `/comborush` = `/cr`.

## Источники очков
`KILL` убийство · `MINE` руда · `HARVEST` урожай · `SHOOT` попадание снарядом по враждебному мобу с 10+ блоков ·
`BREW` зелье из стойки · `ENCHANT` зачарование · `BREED` разведение · `TRADE` сделка с жителем · `FISH` улов.

BREW / ENCHANT / BREED / TRADE / FISH работают без миксинов: датапак содержит скрытые достижения
(`data/combo-rush/advancement/trigger/`), по выдаче которых запускается функция
(`data/combo-rush/function/trigger/`), она снимает достижение и вызывает служебную команду `/cr internal <тип>`.
Для этого функции должны иметь уровень прав 2 (`function-permission-level=2` в server.properties — значение по умолчанию).

## Ранги и сброс
- Ранг считается отдельно для каждого существа: 1-й сброс на нём → ранг 1 … ранг 5 — максимум.
- Эссенция за сброс: ранг 1 → 15, 2 → 20, 3 → 25, 4 → 30, 5 → 35; при уже имеющемся ранге 5 → 40.
- Сбрасывается: монеты, усилители, уровень, доп. слоты, события, статистика забега. Каждый забег начинается с 3 слотов.
- Сохраняется: ранги, эссенция, число сбросов, статистика `life_*`, лучший результат, косметика, открытые существа/усилители.

## Акции (data/<modid>/promos/*.json)
```json
{
  "name": "Новогодний бонус",
  "announce": "Текст в чат при старте",
  "enabled": true,
  "start": "12-20", "end": "01-20",
  "date_start": "2027-03-14", "date_end": "2027-03-14",
  "weekdays": ["SATURDAY", "SUNDAY"],
  "effects": [ { "type": "shop_discount", "value": 0.15 } ]
}
```
- Период: `start`/`end` (каждый год, поддерживается переход через Новый год) **или** `date_start`/`date_end` (разовый). `weekdays` можно добавить к любому из них.
- Эффекты: `shop_discount`, `score_multiplier`, `coin_bonus`, `reroll_discount`, `sell_bonus`.
- Дата берётся с сервера (часовой пояс системы). Пока акция идёт — сиреневая полоска сверху у всех игроков.
- Файлы с `"enabled": false` не включаются сами, но их можно запустить `/cr promo start <id>`.
  Имя файла = id акции. Чтобы отключить выходные: `"enabled": false` в `promos/weekend.json`.
- Сезонные усилители: в JSON усилителя поле `"promo": "<id акции>"` — продаётся только пока акция идёт.

## Косметика (data/<modid>/cosmetics/*.json), цена в эссенции
Типы: `pet` (обычный моб, всегда следует за игроком, неуязвим, не несёт яйца, клиентских модов не нужно),
`title` (префикс через команду скорборда, виден в чате/табе/над головой), `trail` (частицы при движении).
Надеть можно по одному предмету каждого типа. Косметика не теряется при сбросе.

## Формат усилителя (data/<modid>/boosters/*.json)
Поля: `name`, `description`, `icon`, `price`, `min_level`, `unlock_resets`, `promo`, `negative_allowed`, `effects[]`.
Эффект: `type`, `source` (см. источники очков или ALL), `value`, а также необязательные `condition`, `scale`, `per`, `max`.

**Типы очковых/экономических эффектов:** `chips_per_action`, `chips_multiplier`, `mult_add`, `mult_times`, `combo_step`,
`combo_window` (секунды), `coin_bonus`, `shop_discount`, `reroll_discount`, `sell_bonus`, `interest` (value — максимум, per — монет за 1 монету).
**Игровые эффекты:** `attribute` (id, value, operation), `status_effect` (id).

**Масштабирование:** значение × floor(stat / per), не больше `max` шагов. Для `mult_times` и `chips_multiplier` с `scale`
итог = 1 + value × шаги.
Ключи `scale`: `kills`, `ores`, `crops`, `shots`, `brews`, `enchants`, `breeds`, `trades`, `fish`, `gold_medals`, `events` (забег) ·
`life_<то же>`, `life_events` (всё время) · `resets`, `rank`, `essence`, `coins`, `level`, `boosters`, `free_slots`, `score` ·
`health`, `armor`, `hunger`, `xp_level`, `unique_items`.

**Условия `condition`:** `night`, `day`, `low_health`, `full_health`, `overworld`, `nether`, `end`, `underground`, `high`,
`sneaking`, `sprinting`, `raining`, `hungry`, `no_armor`.

## Существа (data/<modid>/species/*.json)
`score_mult` по источникам (`ALL` — для остальных), `shop_price_mult`, `effects`, `default_unlocked`, `unlock_resets`.
В меню `/species` помещается 7 существ.


## Режиссёр (data/<modid>/director/*.json)
В начале каждого 5-минутного события Режиссёр выбирает сценарий (не два раза подряд, по весу, с учётом `min_event` —
среднего номера события игроков онлайн). Сценарий может менять правила подсчёта и спавнить мобов:
```json
{
  "name": "Осада", "description": "…", "weight": 6, "min_event": 6,
  "source_mult": { "KILL": 1.25 }, "mult_add": 0.25, "combo_step": 0, "combo_window": 0, "coin_bonus": 0.10,
  "weather": "thunder",
  "spawns": { "interval": 600, "per_player": 4, "cap": 16, "radius_min": 10, "radius_max": 18,
              "entities": ["minecraft:zombie", "minecraft:skeleton"] },
  "mark": { "enabled": true, "score_mult": 1.5, "boss_entity": "minecraft:zombie", "boss_name": "Охотник на {player}",
            "boss_health": 60, "boss_health_per_event": 3, "bonus": 300, "bonus_per_event": 40 }
}
```
- **Метка:** случайный игрок получает свечение и ×`score_mult` к очкам; рядом появляется охотник (с таким же свечением).
  Убийца охотника получает бонусные очки, помеченный — половину. Не убили до конца события — охотник исчезает.
- Мобы события не дропают лишнего: в конце события все помеченные тегом `cr_event_mob` удаляются.
- Название сценария показывается в боссбаре («Событие «Осада»: 4:12»).

## Таблица лидеров
Файл `combo-rush-leaderboard.json` в папке мира. Обновляется после каждого события, сброса, входа и выхода игрока.
Таблицы: `best` (лучший результат за событие), `score` (очки за всё время), `ranks` (сумма рангов), `kills`, `events`.

## Существа: условия
`conditional_mult: [{ "condition": "night", "source": "ALL", "value": 1.5 }]` — множитель очков при условии (список условий выше + `dark`),
`combo_step_mult` — скорость роста серии (0.6 = на 40% медленнее).
Открытие сбросами: Алхимик 1, Вор 2, Русал 3, Нежить 4, Голем 5. В меню `/species` помещается 14 существ.

## Интерфейс (клиентский мод)
Мод теперь нужен и на клиенте: справа на экране рисуется панель счёта и карточки усилителей. Без клиентского мода игрок видит
старый вариант (строка в action bar), всё остальное работает как раньше.

- **Панель:** таймер, общий счёт, блоки «фишки × множитель», полоса времени серии, монеты, существо и ранг.
- **Карточки:** цвет по типу (синий — фишки, красный — множитель, золотой — экономика, зелёный — игровой, фиолетовый — гибрид,
  чёрный с белой рамкой — негативный). Лента внизу показывает текущую силу усилителя (для растущих усилителей число меняется
  по ходу игры), тусклая карточка — эффект сейчас не работает (не выполнено условие).
- **Анимация подсчёта:** база фишек и множитель → каждый сработавший усилитель по очереди подпрыгивает и показывает «+N» / «×N»
  (звук растёт по тону), затем итог «+очки» влетает в счёт, панель трясётся. Если действий много, анимации автоматически ускоряются.
  Поправки существа, события, Метки и «Повтор» (убывающая отдача) показываются над блоками.
- **Баннер** в начале и в конце события.
- **Команды клиента:** `/crhud` — скрыть/показать, `/crhud sound` — звуки подсчёта, `/crhud results` — показать итоги прошлого события ещё раз.
- Размеры, цвета и позиция — константы в начале `client/HudRenderer.java` (`TOP`, `CARD_W`, цвета). Если места не хватает,
  колонка уменьшается автоматически.
- Данные идут одним сетевым пакетом `HudPayload` (тип + JSON): список усилителей — только при изменении, состояние — раз в секунду,
  «поп» — на каждое очковое действие.

## Редкость усилителей
Поле `"rarity"` в JSON: `common`, `uncommon`, `rare`, `epic`, `legendary`. Влияет на шанс появления в магазине
(веса 60 / 28 / 14 / 6 / 2), цвет названия и рамки карточки в HUD (эпические и легендарные пульсируют). В магазине у каждого
усилителя указана редкость. Сейчас: 23 обычных, 21 необычный, 17 редких, 10 эпических, 7 легендарных.

## Уровни, издания и расходники
- **Уровень усилителя** 0–5: каждый уровень усиливает положительные очковые и экономические эффекты на 20% (минусы не растут).
- **Издания:** фольга (+25 фишек к каждому действию), голограмма (+0.4 к множителю), полихром (×1.2 к множителю).
- **Расходники** (2 слота, действуют на усилитель, только в магазине): Свиток силы, Великий свиток, руны фольги/голограммы/полихрома/хаоса,
  Зеркало эха (копия усилителя), Тигель (случайный усилитель той же редкости), Расширитель (+1 слот), Талисман удачи (бесплатный перекрут).
  Использование: ЛКМ по расходнику внизу магазина → ЛКМ по нужному усилителю. ПКМ по расходнику — продать.
  Новые расходники — JSON в `data/<modid>/consumables/` (`action`: level_up, level_up_all, edition, random_edition, duplicate, reroll_booster, add_slot, free_reroll).

## Синергии между игроками
- `aura_mult_add`, `aura_mult_times`, `aura_chips`, `aura_coin_bonus` (+ `radius`) — эффект получает владелец и все союзники в радиусе в том же измерении.
  В анимации подсчёта такой бонус показывается с названием усилителя союзника.
- `share_score` — владелец получает долю очков, заработанных союзниками рядом («Командный дух»).
- `scale: "team_score"` — масштабирование от очков остальных игроков в текущем событии («Эстафета»).

## Босс-блайнды
У каждого игрока каждое 5-е событие забега (5, 10, … 50) — босс-блайнд с дебафом. Дебаф выбирается случайно на всех «боссовых» игроков,
остальные играют обычное событие. Награда за бронзу и выше: бонус монет и случайный расходник; при провале ничего не теряется.
Дебафы: `data/<modid>/debuffs/*.json` — Тишина, Голод, Хрупкость, Пацифист, Обвал, Неурожай, Слепота, Рваный ритм, Свинцовые ноги, Высокая планка.
Поля: `silence`, `hunger_target`, `fragile`, `blind`, `target_mult`, `source_mult`, `combo_window`, `status_effect`, `coin_bonus`, `reward_consumable`.

## Защита от абуза
Рудные блоки, **поставленные игроком**, очков не дают (закрывает «шёлковое касание → поставить → сломать»). Список хранится в файле
`combo-rush-placed.json` в папке мира. Ограничения: блок, сдвинутый поршнем, считается новым; список хранит до 200 000 позиций на измерение.

### Экран итогов события
После каждого события у игрока с клиентским модом появляется панель итогов на ~13 секунд: общий счёт (считает вверх), разбивка очков по источникам
(убийства, руда, урожай, выстрелы, зелья… плюс «Бонусы» и «Командный дух») с анимированными полосами, шкала порогов Бронза → Серебро → Золото → Платина
с подсказкой «до следующей медали», медаль с анимацией и искрами, начисленные монеты (база, бонусы, проценты, награда босс-блайнда, выданный расходник)
и монеты, которые перелетают в счётчик монет в правой колонке. Без клиентского мода в чат приходит строка «Источники: …».

### Расходники и подсказки
- Под карточками усилителей показаны 2 слота расходников.
- Подсказки: открой чат (T) или инвентарь, когда курсор свободен, и наведи его на карточку усилителя или расходника:
  название, редкость, тип, описание, уровень, издание, текущее значение и пометка, если эффект сейчас не работает.
