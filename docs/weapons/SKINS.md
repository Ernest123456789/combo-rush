# Weapon models & skins (11 guns + Claw knife)

Generated by `tools/weapon_gen` (Python + Pillow). Model frame matches an94 (muzzle +z, x centre -12.72), so the same `display` JSON applies.

## Files per gun `<id>`
- `geo/item/weapon/<id>.geo.json`, `textures/item/weapon/<id>.png`, `animations/item/weapon/<id>.animation.json`, `models/item/<id>.json`
- Animations: `animation.<id>.draw / shoot / reload / inspect`
- Bones: `weapon` (grip pivot), `receiver`/`slide`, `bolt`, `trigger`, `magazine`, `stock`, `barrel`, `scope` (AWP), `FX_muzzle_flash`, `FX_ejected_case_0`

## Skins
Every part of the gun owns a rectangular **island** in the texture (see `docs/weapons/<id>_uv_layout.json`, `<id>_template.png`).
A skin = a PNG of the same size as the base texture, repainted island by island; geometry/UV never change.
Planned path: `textures/item/weapon/skins/<id>_<skin>.png`. Never move islands - skins rely on the fixed layout.

## Regenerating
`cd tools/weapon_gen && python3 -c "from guns import *; g=ak47(); g.paint(); g.img.save('ak47.png')"` (see wgen.py: `Gun.box`, `Gun.paint`, `Gun.geo`).

## Wired in game (Arsenal)
- `item/GunDefs.java` (generated list of guns / skins), `CRGunItem` (GeckoLib controller `main`: draw/shoot/reload/inspect, silencer variants `_ns`), `CRKnifeItem` (draw/attack/attack2/inspect), `GunGeoModel` (shared geo + animations, per-skin texture), `WeaponKeys` (R reload, V inspect, G silencer).
- Silencer (USP-S, M4A1-S): stack custom data `nosil`; animations `idle_ns`, `sil_off`, `sil_on`, and `<name>_ns` variants hide the `silencer` bone (scale 0.001).
- Skins: `textures/item/weapon/skins/<gun>_<skin>.png`; every skin is its own item `combo-rush:<gun>_<skin>` (model json copied from the gun), data `data/combo-rush/weapons/<id>.json`.
- Case: `data/combo-rush/cases/arsenal.json` (CS-like odds: 79.9 / 16 / 3.2 / 0.64 / 0.25 %). Skins and case art: `tools/weapon_gen/skins.py`, `case_gen.py`.
- To add a skin: add a row to `SKINS` in `skins.py`, run `export_all.py` + the repo generator, add the item to `GunDefs` (lang / weapons json / model json are generated).
